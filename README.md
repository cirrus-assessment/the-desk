# The desk

Public, Slack-shareable wrapper for **The desk**, the Cirrus monthly newsletter.

`index.html` carries Open Graph / Twitter Card metadata (so the link unfurls with
a title, description and preview image when shared in Slack or chat) and embeds the
live report in an iframe. The report itself stays behind Google sign-in.

- Preview image: `desk-og.png` (1200x630)
- Live URL: https://cirrus-assessment.github.io/the-desk/
